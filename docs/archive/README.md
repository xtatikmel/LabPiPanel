# Documentación histórica

Los documentos de esta carpeta describen versiones anteriores del proyecto:
la aplicación monolítica de la raíz, análisis de integración, planes de
migración y reportes de auditoría.

**No son la fuente de verdad.** La documentación vigente está en
[`docs/`](../README.md).

Se conservan para trazabilidad y para recuperar contexto sobre:

- la arquitectura legacy (`labpipanel.py`, `thermal_experiment.py`),
- el hardware real y sus parámetros,
- decisiones y auditorías previas.

> La carpeta [`docs/guias/`](../guias/) también es documentación heredada. No se
> pudo mover a este directorio porque el sistema de archivos lo impide sin
> elevación; trátala igual que el contenido de `archive/`.

Si un documento de esta carpeta contradice el README o la guía de ejecución,
prevalece la documentación vigente.
